# Руководство пользователя — СПО «Афина NextGen» (трек Р, релизная линия)

## 1. Вход
1. Откройте `http://127.0.0.1:8470/` (сервер запускает администратор).
2. Первый вход в системе = bootstrap: введите логин/пароль — будет зарегистрирован «Администратор системы». Далее пользователей регистрирует только администратор (роль по Приложению Н ТЗ).
3. Роль определяет доступные операции (RBAC проверяется на КАЖДОЙ операции; отказ логируется в аудит).

## 2. Вкладки рабочего клиента

## 3. Ключевые правила, которые видит пользователь
- Расчёт без паспорта не выдаётся; паспорт содержит версии, хэш входов, 4 компонента неопределённости.
- Результат сценария/прогноза маркирован «оценка (не факт)».
- Суррогат маркирован «СУРРОГАТ» и вне области применения не выдаёт достоверных значений.
- Замечание согласовывает НЕ его автор (Maker–Checker); закрытие — только с основанием.
- Баллы начисляются только за проверяемый результат; ошибочные начисления отзываются с объяснением.

## 4. Горячие действия
- «▶ Рассчитать» — постановка в очередь (интерфейс не блокируется, ARC-003).
- Ctrl+K — поиск (демонстратор v12); в рабочем клиенте — навигация по вкладкам.
