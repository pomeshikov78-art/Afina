# Перечень известных ограничений и технического долга (позиция 18, §11.1)

Честная фиксация на дату релиза g5 (18.10.2026). Статусы: **СТЕНД** — требует целевой платформы; **ДАННЫЕ** — требует данных Заказчика; **ОПЦИЯ** — подключаемый компонент; **ДОЛГ** — технический долг.

| № | Ограничение | Статус | Что сделано / что нужно |
|---|---|---|---|
| 1 | Единый .exe-загрузчик собирается только на Windows-стенде | СТЕНД | Скрипты NSIS/Inno готовы (src/installer/), проверка целостности при запуске реализована; сборка и подписание — на стенде |
| 2 | Порт ядра C++/Vulkan с регрессией по эталонам (MOD-002/004) | ДОЛГ | Эталонная реализация Python подтверждена MAT-01…10; backend фиксируется в паспорте; при портировании прогон тех же эталонов обязателен |
| 3 | PostgreSQL/PostGIS в проде | ДОЛГ | Схема идентична логической (src/db/schema_postgres.sql); текущая поставка — SQLite (одноместовая/режим Б) |
| 4 | Тайлы рельефа Евразии | ДАННЫЕ | Загрузчик, кэш XYZ, манифест переноса и RSC-генерализация готовы; данные поставляются Заказчиком (MTW/DB3D) |
| 5 | SXF/SITX/DB3D-адаптеры | ДАННЫЕ | Реестр лицензий G0 (путь A/B); round-trip протокол готов; адаптеры подключаются после лицензирования форматов |
| 6 | Локальная LLM | ОПЦИЯ | Детерминированный RAG + объяснения работают без весов; GGUF-раннер — подключаемый компонент при поставке весов (внешние API запрещены AUT-002) |
| 7 | Сертифицированное СКЗИ | СТЕНД | Интерфейс CryptoProvider готов; замена методов на вызовы СКЗИ по классу системы; наличие СКЗИ ≠ сертификация Системы |
| 8 | Прогнозная техника до 2036 | ДАННЫЕ | В каталоге маркирована «ПРОГНОЗ — не подтверждено» (EQP-001); подтверждение — данные Заказчика |
| 9 | Полный 3D Ray-Tracing/SBR, UTD | ДОЛГ | LOS/Френель/дифракция (G1) работают; полный SBR — с портом на GPU (п. 2) |
| 10 | IFC: Brep/CSG/Tessellation | ДОЛГ | SweptSolid (призмы) реализован; неподдержанные представления УЧИТЫВАЮТСЯ честно в отчёте загрузки |
| 11 | Нагрузочные S3/S4 на целевом железе, MIL-05/10 аппаратурная часть, AUT-T04 | СТЕНД | Программы испытаний в ПМИ; нормы §7.2 на эталонной CPU-реализации выполнены (S1 3,4 мс / S2 0,22 с / S3 0,55 с) |
| 12 | Push-уведомления браузера (Notification API) | ДОЛГ | Шина, дедупликация, эскалация и центр уведомлений работают; браузерный Push — расширение клиента |
| 13 | MinIO/RabbitMQ | ОПЦИЯ | Файловое хранилище и локальная очередь покрывают режим Б; подключение — после проверки лицензий (AGPL) |
