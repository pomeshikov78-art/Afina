# Руководство инженера — расчётное ядро ENG6+ и расширение G4

## 1. Расчётные функции (§4.5.4)
RF-01…09, NET-01/02, PWR-01, THM-01, REL-01, OPT-01, LCC-01 — `src/afina/eng6/`.
Через REST: `POST /api/v1/calc {"function": "RF-03|RF-07|PWR-01|OPT-01|LCC-01|COSIM-01", ...}` → job_id → `GET /api/v1/calc/<job_id>`.

## 2. Режимы и уровни (§4.5.1–4.5.2)
Preview — быстрая оценка; Engineering — рабочий режим; HighFidelity/Verification — с повышенной детализацией. Уровни L0…L4 задают шаг сетки и состав учитываемых факторов. Режим и уровень фиксируются в паспорте запуска.

## 3. Домены применимости (MOD-003)
Каждая модель имеет домен (например, Окамура–Хата: f 150–1500 МГц, d 1–20 км, h_bs 30–200 м). Выход за домен → исключение ApplicabilityError, расчёт блокируется или помечается — результат как достоверный НЕ выдаётся.

## 4. OPT-01 (§4.5.4, ENG-006)
`{"variants":[...], "criteria":[{key,name,direction,weight,hard_min,hard_max}], "constraints":[{type:subset_of|forbidden_value|all_required|numeric_bound,...}]}`.
Порядок: фильтрация по жёстким ограничениям (отклонённые — с причиной) → Парето → взвешенное ранжирование. Нарушитель ограничения не может быть «лучшим».

## 5. Co-Simulation (§4.5.6)
COSIM-01: цепочка PWR-01→THM-01→REL-01. Обязательны: ID сценария, объявленные порты с единицами (необъявленный порт не передаётся), проверка единиц ENG-004, версии решателей в результате, ошибка решателя останавливает прогон без подмены значениями по умолчанию.

## 6. Суррогаты (§4.5.8, MOD-006)
`POST /surrogate/train` (точки ПРОВЕРЕННОГО решателя) → статус «Проверяется» → `POST /surrogates/<id>/compare` (независимые точки против основного решателя) → `POST /surrogates/<id>/validate` (роль verify, с основанием) → «Валидирована для указанной области». Вне бокса домена — статус out_of_domain. Отключение — роль «Администратор данных».

## 7. Паспорт запуска (§4.5.10)
Каждый расчёт: run_id, модель+версия, хэш входов, CRS/единицы, среда выполнения, 4 компонента неопределённости, применимость+допущения. Повтор на сохранённом снимке даёт результат в допуске (MOD-002, протокол MAT).

## 8. Эталонные сценарии
Приложение Е (data/) + `pmi/run_mat.py` — MAT-01…10 (38 тестов): аналитические эталоны, размерности, сходимость, границы, неопределённость, сопряжение, воспроизводимость, суррогат, оптимизатор, регрессия.
