# Руководство сопровождения

## 1. Состав кодовой базы
- `src/afina/eng6/` — расчётное ядро (units, models, rf, net, pwr_thm, rel, opt, cosim, surrogate, passport, runner);
- `src/afina/gis/` — ГИС-ядро (crs, io_formats, mtw, tiles_rsc, roundtrip, models3d);
- `src/afina/server/` — ядро хранилища (core.py) и REST API (app.py);
- `src/afina/` — twin.py, cfg.py, ntf.py, dat.py, vt.py, game.py, ai/, catalog/, units.py;
- `src/client/index.html` — рабочий веб-клиент (раздаётся сервером);
- `src/tests/`, `src/pmi/` — тесты (145) и генераторы протоколов;
- `src/installer/`, `src/tools/`, `src/db/` — поставка, инструменты, целевая схема БД.

## 2. Зависимости
Только стандартная библиотека Python 3.11+ (stdlib-only, SBOM — Приложение Л). Внешние пакеты НЕ требуются; подключение локальной LLM (GGUF) — опция, точка расширения `afina/ai/`.

## 3. Регламент изменения кода
Изменение проходит CR-цикл (§4.8.2): Предложено→Внесено (линия фиксируется ДО)→Проверено→Утверждено (не автором). После изменения обязательны: `python3 -m unittest discover -s tests -p "test_*.py"` (145/145), `pmi/run_mat.py` (регрессия эталонов MOD-002/010), протоколы `pmi/*`.

## 5. Типовые неисправности
- «порт занят» — смените --port; - «401» — сессия истекла (TTL 8 ч), повторный вход;
- «403 ОТКАЗ RBAC» — операция не для этой роли (матрица Прил. Н), событие в аудите;
- очередь стоит — проверьте `GET /api/v1/queue`; задания персистентны, перезапускаются при старте.
