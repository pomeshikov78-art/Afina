# Руководство администратора — сервер, БД, безопасность

## 1. Запуск
```bash
cd src
python3 -m afina.server.app --db ../data/afina.db --port 8470 \
  --requirements ../data/Афина_Реестр_требований_ПриложениеА.json \
  --tz ../Афина_Техническое_задание.md [--no-ai]
```
- `--no-ai` полностью отключает ИИ-слой (AI-003); ГИС и инженерное ядро работают штатно.
- Первый вход = bootstrap «Администратора системы»; последующая регистрация пользователей — только администратором.

## 2. Роли (Приложение Н)
9 ролей; операции RBAC проверяются на сервере для каждого запроса; отказ записывается в аудит (SEC-001). Ключевые разделения: объекты создаёт «Проектировщик»; базовые линии и арбитраж — «Уполномоченный утверждающий»; согласование замечаний — не автор (Maker–Checker, SEC-005); независимая проверка сценариев/суррогатов — «Инженер-верификатор»; отключение суррогатов и словари — «Администратор данных».

## 3. Хранилище
SQLite (поставка одноместовая/режим Б). Логическая схема идентична целевой PostgreSQL+PostGIS (`src/db/schema_postgres.sql`) — единое ядро в обоих режимах (AUT-001). Таблицы G3/G4: changes, conflicts, scenarios, surrogates, vt_*, game_awards.

## 4. Аудит и безопасность
- Каждая запись аудита связана хэш-цепочкой; `GET /api/v1/audit/verify` — проверка целостности.
- Аутентификация: scrypt + HMAC-токены; точка подключения сертифицированного СКЗИ — `CryptoProvider` (core.py): замена методов hash_password/sign. Наличие СКЗИ не означает сертификации всей Системы (Г0, модель угроз).
- Экспорт: SEC-004 — персональные/закрытые атрибуты исключаются; перенос не создаёт сетевого моста (AUT-005).
- Внешних обращений нет: подтверждено AUT-T02 (44 теста при заблокированном сокете, 0 исходящих) и прогоном §13.2 в режиме Б.

## 5. Резервное копирование (§4.15)
```bash
python3 tools/backup.py backup --db ../data/afina.db --dest ../backups --extra ../data
python3 tools/backup.py drill  --db ../data/afina.db --dest ../backups   # полный цикл + RTO
python3 tools/backup.py verify --manifest ../backups/MANIFEST_*.json
python3 tools/backup.py restore --manifest ../backups/MANIFEST_*.json --target ../data/restored.db
```
Снимок консисентен под нагрузкой (sqlite backup API); манифест хранит sha256 каждого файла; подменный/повреждённый комплект отклоняется ДО восстановления (AUT-T07). RPO = регламентная периодичность (rpo_policy_s в манифесте), RTO измеряется в drill.

## 6. Мониторинг
`GET /healthz` (статус, версия, external_calls=0), `GET /api/v1/queue` (очередь расчётов), `GET /api/v1/analytics/trends`, панель ВТ-08 (`GET /api/v1/vt/panel`). Зависшие задания очереди перезапускаются при старте сервера (персистентность queue.json).
