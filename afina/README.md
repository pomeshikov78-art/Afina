**Быстрый старт (любая ОС с Python 3.11+):**
```bash
cd afina/src
python3 -m afina.server.app --db ../data/afina.db --port 8470 \
  --requirements ../data/Афина_Реестр_требований_ПриложениеА.json \
  --tz ../Афина_Техническое_задание.md 2>/dev/null || \
python3 -m afina.server.app --db ../data/afina.db --port 8470
# клиент: http://127.0.0.1:8470/  (первый вход = bootstrap администратора; вкладки «Жизненный цикл · G3» и «Расширение · G4»)
# тесты:  python3 -m unittest discover -s tests -p "test_*.py"   # 145/145
# протоколы: python3 pmi/run_mat.py && python3 pmi/run_integration.py && python3 pmi/run_mil.py && python3 pmi/aut_t02.py && python3 pmi/run_g3.py && python3 pmi/run_g4.py
# смоуки:    python3 pmi/smoke_g3.py && python3 pmi/smoke_g4.py
# приёмка:   python3 pmi/run_132.py && python3 pmi/run_aut_g5.py && python3 tools/build_delivery.py && python3 pmi/run_acceptance.py
# режим без ИИ (AI-003): добавьте --no-ai
```

## Версионирование

Каждая версия прототипа сохраняется отдельным файлом `Афина_vN.html`; предыдущие версии не изменяются. Состав изменений фиксируется в `Афина_План_работы.md` (раздел 6 «Журнал версий»).

- **Импорт/экспорт round-trip** (GIS-002/003/004, AUT-004/005, SEC-004): фактический пересчёт CRS с записью операции, протокол потерь, проверка версий и целостности, исключение закрытых полей и персональных данных
- **Модуль «Конфигурация»** (§4.8): базовые линии с воспроизводимым архивом, процесс изменения из 8 шагов, SVG-граф анализа влияния CFG-002, реестр изменений (CFG-003), инженерные правила вне кода (CFG-004); фиксация базовой линии — только роль «уполномоченный утверждающий»
- **Модуль «Испытания»** (§4.8.4–4.8.5): реестр стендов и СИ с поверками, предупреждение о недопустимости результатов вне условий применения, цифровой паспорт испытания, связь требований с испытаниями (TST-001/002)
- **Модуль «Отчёты»** (DOC): мастер отчёта с версиями/допущениями (DOC-002: автогенерация ≠ утверждение), комплект поставки из 18 позиций, хронометраж типовых операций (§10.5), печать карт
- **Переключатель ролей** (§3.5, SEC-001/005): 9 ролей, RBAC-отказы с записью в аудит; согласование замечаний и фиксация базовых линий привязаны к роли утверждающего
- **Локальная справка** (AUT-008): термины, горячие клавиши, маркировки результатов
- **Геометрические проверки** (3DM-008, MEC-01): коллизии, сервисные зоны, радиусы изгиба, монтажные ограничения
