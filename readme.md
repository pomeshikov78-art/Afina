# Репозиторий «Afina» — единая платформа планирования и моделирования систем связи

> **Этот файл обновляется после каждого прохода разработки** (регламент единой программы,
> `unified/WORKPLAN.md`). Состояние на: **27.10.2026, проход №5**.

Репозиторий содержит две независимые линии разработки и **единую программу** (`unified/`),
которая соединяет их в один продукт без переписывания ядер:

| Раздел | Что это | Стек | Статус |
|---|---|---|---|
| [`afina/`](afina/) | **Линия A** — СПО «Афина NextGen»: платформа по ТЗ.АФИНА.11.0 (ГОСТ 34.602-2020) — ГИС, каталог средств связи 1940–2036, ОШС, цифровые двойники DT-0…5, RBAC, аудит-хэш-цепочка, ИИ-RAG, ВТ-профиль, геймификация, веб-клиент WebGL, демо-линия v1–v12 | Python 3.11, **stdlib-only** | Рубежи G0–G5 закрыты; **145/145** тестов; проект акта «РЕКОМЕНДУЕТСЯ К ПРИЁМКИ» |
| [`eng6-service/`](eng6-service/) | **Линия B** — ENG6-PLAN: промышленный вычислительный сервис планирования (MILP: ресурсы/маршруты/расписание) вокруг вендора ENG6 v5.1.0 (151 модель MLIB), извлечённого из `comms_planner_v8.0_headless.html` | Node.js ≥ 20.11, **0 зависимостей** | **125/125** тестов; conformance 33+5; selfcheck 21/21; 10⁵ узлов за ~40–47 с |
| [`unified/`](unified/) | **Единая программа**: интеграционный мост, кросс-верификация ядер, единые данные/аудит/очередь/RTM/манифест/CI/deploy, единое рабочее место (UI PoC) | Python + Node, stdlib/zero-deps | Фаза 1 — ключевые контуры закрыты; **42/42** теста моста; все протоколы в `unified/protocols/` |

Корневые артефакты: `comms_planner_v8.0_headless.html` (изделие-источник ядра ENG6),
`eng6_core_extracted.js` (дубликат вендора), `chat-export-…json` (история формирования ТЗ).

```
   → паспорт ENG-001 (отпечатки ОБОИХ вычислительных путей, sha256 вендора)

   → сшивка трёх журналов: мастер-цепочка платформы + контур + леджер = ANCHORED
```
