# unified/installer — сборка установщика Windows x64 (.exe)

**Результат:** `dist/AfinaUnified-Setup-1.0.0.exe` — self-contained установщик
единой программы: Python 3.11.9 (embeddable) и Node.js v20.18.1 (node.exe)
встроены — целевая машина НЕ требует предустановленных рантаймов.

| Параметр | Значение |
|---|---|
| Размер | ~28.8 МБ (LZMA solid: 95.5 МБ стенда → 30 %) |
| Файлов в бандле | 194 (+ bundled-рантаймы) |
| sha256 (**1.0.1**, текущая) | `94d7bd1598ae849b424406802c48baaf9fb7c6fe55f4107a80d372ee6771417c` |
| sha256 (1.0.0, ОТЗУНА — дефект OBS-14) | `e0970924b91f84a2…` — платформа не стартовала (queue_path), сирота node.exe |
| Тулчейн | NSIS v3.08 — **кросс-сборка на Linux** (apt install nsis) или нативно на Windows |
| Целевая ОС | Windows 10/11 x64 |

## Сборка (воспроизводимая)

```bash
# Linux (кросс) или Windows (нативно):
python3 unified/installer/build_windows_exe.py --version 1.0.0
# рантаймы скачиваются с официальных дистрибутивов (кэш ~/.cache/afina-installer):
#   python.org  → python-3.11.9-embed-amd64.zip (11.2 МБ)
#   nodejs.org  → node-v20.18.1-win-x64.zip (29.6 МБ, берётся только node.exe)
# вариант без рантаймов (требует системные Python/Node): --skip-runtimes
```

Этапы сборки: стенд `build/payload/` (дерево репозитория без мусора: node_modules,
var, кэш, протоколы исключены) → `bundle_manifest.json` (sha256 **каждого** файла,
SEC-002) → `makensis` → `dist/*.exe` + `dist/MANIFEST.txt` (sha256 установщика).

## Что устанавливается и как работает

```
C:\Program Files\AfinaUnified\
├── runtimes\python\ · runtimes\node\node.exe   встроенные рантаймы
├── afina\            платформа (src: пакет + клиент; data: реестры/приложения; ТЗ)
├── eng6-service\     вычислительный контур (core+vendor ENG6 v5.1.0, api, frontend…)
├── unified\          мост, рабочее место (ui\workspace.html), verify_install, RTM
├── Афина.bat         запуск (pythonw run_unified.pyw — без консоли)
├── Остановить.bat    корректная остановка (pid-файл)
├── Проверка.bat      серверные проверки установки (verify_install --skip-xver)
├── run_unified.pyw   единый загрузчик: целостность → порты → контур+платформа → браузер
└── bundle_manifest.json
```

Порядок запуска (`run_unified.pyw`):
1. **SEC-002**: sha256 всех 194 файлов против манифеста — подмена/утеря → отказ + сообщение;
2. порты 8080/8470 (заняты → свободные); движок — subprocess `node.exe api/main.mjs`;
3. платформа — в процессе (create_server + сид каталога, как штатный загрузчик линии A);
4. ожидание `/healthz` обоих → браузер: `workspace.html?engine=…&platform=…`;
5. данные — в `%LOCALAPPDATA%\AfinaUnified\` (БД, журналы, pid, аудит-леджер):
   Program Files на запись недоступен — это осознанное разделение.

### Чек-лист приёмки на Windows-стенде (15 минут)
1. Установить .exe (UAC) → ярлыки «Афина» (рабочий стол/Пуск) существуют;
2. «Афина — запуск» → браузер открыл рабочее место; статус-бар: «мост: платформа на связи»;
3. «Демо-сценарий» → «▶ Рассчитать план» → PARTIAL/B…C, карта/маршруты/волны;
4. Фрейм платформы: первый вход — bootstrap администратора; вход выполнен;
5. «Проверка установки» → вердикт «ВСЁ РАБОТАЕТ» (14 проверок, XVER пропущен как требующий node в PATH — bat его добавляет, так что фактически 15);
6. «Остановить» → порты освобождены (`netstat -an | findstr 8080`);
7. Подмена файла (дописать байт в `unified/bridge/xverify.py`) → запуск ОТКЛОНЁН (SEC-002) → восстановить из переустановки;
8. `%LOCALAPPDATA%\AfinaUnified\`: afina.db, unified.log, engine.log, unified_audit.ndjson — созданы;
9. Удаление через «Параметры → Приложения» → дерево удалено, данные — по подтверждению.

### Известные ограничения
* Возможна потребность в VC++ Redistributable 2015–2022 (node.exe) на «голой» Windows — указано в README_УСТАНОВКА.txt;
* Антивирус/SmartScreen может ругаться на неподписанный .exe — лечится подписью заказчика;
* OneDrive/漫游-профили: LOCALAPPDATA всегда локальный — ок для режима Б.
