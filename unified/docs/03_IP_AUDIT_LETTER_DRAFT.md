## 1. Существо вопроса

При выполнении работ по Дополнению №2 к ТЗ (ГОСТ 34.602-2020) «Промышленный
вычислительный сервис на базе headless-ядра ENG6» из поставленного изделия
`comms_planner_v8.0_headless.html` (2 551 730 байт) было **извлечено без
изменений** нативное математическое ядро ENG6 v5.1.0:

* объём: 677 168 знаков исходного текста JavaScript;
* публичная поверхность: 69 ключей фасада, 151 модель MLIB;
* контрольная сумма: sha256 `adb610c9eee1ca17b257cbc6087e2278fdde3eef92f3b6a360cfb51968d48b20`;
* конформанс: 33/33 эталонные проверки selfTest + 5/5 регрессионных сценариев
  изделия воспроизводятся без расхождений.

Ядро используется как **вендор** (единственный источник истины по математике
распространения радиоволн, ADR-001): исполняется в изолированном контексте V8
без доступа к сети, ФС на запись и браузерным API; **не модифицируется**
(§9.3.1 Дополнения №2: любые правки вендора недопустимы без повторного
конформанс-протокола).

## 3. Текущие ограничения, принятые исполнителем добровольно

1. Единая программа поставляется **только внутри контура заказчика**;
   коммерческое распространение до решения правообладателя не осуществляется.
2. `eng6-service/package.json` сохраняет `license: UNLICENSED` — статус
   намеренно не менялся.
3. Кросс-верификация (протоколы XVER/ARC-002) исполняет ядро **только для
   сверки значений** (чтение результатов примитивов), не извлекая и не
   публикуя его исходный текст в производных работах.

## 4. Существенное обстоятельство, требующее решения заказчика

Репозиторий `github.com/pomeshikov78-art/Afina` в настоящее время **публичен**
и содержит извлечённое ядро (`eng6-service/core/vendor/eng6_core.js`, корневой

1. перевести репозиторий в private (Settings → Danger Zone → Change visibility);
2. при необходимости — удалить из истории файлы ядра (`git filter-repo`) и
   перевыпустить историю; факт прежней публичности при этом сохраняется и
   должен быть раскрыт правообладателю.
