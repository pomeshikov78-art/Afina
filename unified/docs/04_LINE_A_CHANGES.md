# 04_LINE_A_CHANGES — реестр изменений артефактов линии A (afina/)

Политика единой программы: артефакты линий A и B **не изменяются** без явного
решения владельца. Решением заказчика от 26.10.2026 («всё. 1,2,3,4») правки
линии A разрешены в объёме прохода №5. Каждая правка регистрируется здесь с
обоснованием, точным местом, проверкой совместимости и тестами.

Принцип всех правок: **обратно совместимы** (новое поле с дефолтом / новый
маршрут / новый скриптовый блок), юнит-набор линии A (145 тестов) остаётся
зелёным БЕЗ изменения самих тестов линии A.
